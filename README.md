# Cafe Website

A modern cafe and coffee shop web application built with React, Vite, and Tailwind CSS.

## Features

- Interactive and responsive coffee shop user experience
- Dynamic menu and featured coffee specials
- Rich media previews, video backgrounds, and animations
- Styled with modern Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Install dependencies
npm --prefix "cafe website" install

# Start development server
npm run dev
```

### Build

```bash
npm run build
```
